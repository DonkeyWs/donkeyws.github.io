** 楔子(Prologue)

~clang~ 和现代 ~C++~ 正在逐步成为嵌入式开发的可用选择方案，本文尝试通过现代 ~C++~ （ ~C++17~ ）实现个简单的嵌入式项目，
以了解使用现代 ~C++~ 开发嵌入式项目的方法步骤和注意事项，并从中探索在嵌入式项目中使用 ~C++~ 的优劣势。

** 环境准备(Setup)

** STM32F103

- CPU：Cortex-M3
- Thumb 指令集
- 无 ~FPU~ ，通常使用 ~soft-float~

对于 ~clang++~ 来说，核心编译参数如下：

#+begin_src bash
  # -Og for debug version, -Os for release version
  # reduce result size: -ffunction-sections -fdata-sections -fno-common, with link options: -Wl,--gc-sections
  # bare metal options: -ffreestanding -fno-builtin
  # remove C++ features: -fno-exceptions -fno-rtti -fno-threadsafe-statics -fno-use-cxa-atexit
  # safety features: -Wall -Wextra -fno-strict-aliasing -fno-stack-protector
  --target=thumbv7m-none-eabi -mcpu=cortex-m3 -mthumb -mfloat-abi=soft -std=c++17 -Os -g3 -ffunction-sections -fdata-sections -fno-common -ffreestanding -fno-builtin -fno-exceptions -fno-rtti -fno-threadsafe-statics -fno-use-cxa-atexit -Wall -Wextra -fno-strict-aliasing -fno-stack-protector
  #
  # Link options:
  # -T linker/stm32f103c8tx.ld
  # -Wl,--gc-sections
  # -Wl,-Map=build/firmware.map
  # -Wl,--print-memory-usage
#+end_src
