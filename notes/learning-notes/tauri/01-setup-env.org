** 前置条件(Prerequisites)

*** 系统依赖

~Ubuntu~ 上安装如下系统依赖：

#+begin_src bash
  sudo apt install libwebkit2gtk-4.1-dev \
       build-essential \
       curl \
       wget \
       file \
       libxdo-dev \
       libssl-dev \
       libayatana-appindicator3-dev \
       librsvg2-dev
#+end_src

~macOS~ 上只要安装 ~XCode~ 即可。

*** Rust 安装

按照官方命令：

#+begin_src bash
  curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
#+end_src

*** NodeJS 安装

*** Android 环境

基础的Android环境配置，这里略过，包括JDK和Android SDK和NDK的安装预配置。

按需安装Rust对应的编译目标，这里只支持aarch64：

#+begin_src bash
  rustup target add aarch64-linux-android
#+end_src

*** iOS 环境

#+begin_src bash
  rustup target add aarch64-apple-ios x86_64-apple-ios aarch64-apple-ios-sim
#+end_src

** 修改默认图标

~Tauri~ 创建的应用更换图标需要如下步骤[fn:1]：

1. 准备一个 ~512x512~ 像素的带有 ~RGBA~ 通道的 ~PNG~ ，放到项目根目录，名称为 ~app-icon.png~ 。
2. 运行 ~npm run tauri icon~ 或者 ~cargo tauri icon~ 生成新的图标。


[fn:1] 图标配置：https://v2.tauri.app/es/develop/icons
