** 环境安装(Setup)

#+begin_note
  笔者用的是 =Ubuntu 24.04= 系统，以及家中的一个 =macOS= ，所以后面的操作以这两个平台为主。
#+end_note

在 =Ubuntu= 上安装 ~lilypond~ 非常容易，只需要从软件源中直接安装即可，而且安装过程还会贴心的为你安装好对应的 =Emacs= 扩展：

#+begin_src bash
  sudo apt install -y lilypond
#+end_src

安装完成后，你可以通过 ~lilypond --version~ 来查看是否安装成功，成功的话就会有版本信息输出，对于 =Ubuntu 24.04= 来说，这个版本是 ~2.24.3~ 。
到这里，其实 ~lilypond~ 就已经安装完成，可以使用了，我们可以直接打开编辑器(~Emacs~)编写一个官方例子测试下，创建文件 ~1.ly~ ：

#+begin_src lilypond
  \header{ tagline="" }
  \relative c' {
    f e d c
    b a g a
    b c d e
    f g f e
    d c b a
    g1
  }
#+end_src

之后通过命令行编译：

#+begin_src bash
  # --pdf: 是生成PDF格式的文件
  # -o: 是指定输出文件路径，扩展名会自动添加
  lilypond --pdf -o 1 1.ly
#+end_src

最终会生成一段包含如下旋律的PDF文件，好处就是可以无限放大，清晰保真，打印出来的效果比图片好太多了：

[[file:images/notations.png]]

如果你恰巧也跟笔者一样，使用 ~Emacs~ 编辑器，那么接下来的部分可能对你有所帮助，可以通过配置 ~Emacs~ 来实现友好的 ~lilypond~ 乐谱编辑，
如果你不使用 ~Emacs~ ，那么我推荐你使用[[https://www.frescobaldi.org][frescobaldi]]，这也是官方推荐的所见即所得编辑器之一。

*** Emacs 配置

编辑你的 =Eamcs= 配置文件 ~$HOME/.emacs.d/init.el~ ：

#+begin_src elisp
  ;; 安装 Geiser（使用 use-package）
  (use-package geiser
    :ensure t
    :config
    (setq geiser-active-implementations '(guile))
    (setq geiser-guile-binary "guile"))

  ;; 可选：安装 geiser-guile 包（有些 Emacs 版本需要单独安装）
  (use-package geiser-guile
    :ensure t)

  ;; 可选：安装 paredit（结构化编辑，强烈推荐）
  (use-package paredit
    :ensure t
    :hook ((scheme-mode . paredit-mode)
  	 (geiser-repl-mode . paredit-mode)))
#+end_src

如果是学习或者验证编写的程序，一般的步骤是：

1. ~C-c C-s~ 之后在 ~minibuffer~ 中输入 ~guile~ 作为 ~Scheme~ 的实现；
2. 在 ~buffer~ 中编写代码，之后通过 ~C-c C-c~ 加载并执行当前缓冲区；
3. 根据错误提示修改代码，之后继续执行步骤 ~2~ ，直到代码结果满意；
4. 也可以通过 ~M-x geiser~ 启动 ~REPL~ 窗口，直接执行一些验证操作。

*** 从小星星开始

#+begin_src lilypond
  \version "2.24.4"

  \header {
    title = "Twinkle, Twinkle, Little Star"
    composer = "Traditional"
  }

  melody = \relative c'' {
    \clef treble
    \key c \major
    \time 4/4
    c4 c4 g'4 g4 |
    a4 a4 g2 |
    f4 f4 e4 e4 |
    d4 d4 c2 |
  }

  \score {
    \new Staff \melody
    \layout { }
    \midi { }
  }
#+end_src

这里列出一些打谱常用的基本知识以及 ~lilypond~ 的用法，详细的教程还是参考官方教程更合适。

先给出一个比较简单直观的文件结构，依此来认识下 ~lilypond~ 乐谱文件的基本结构：

#+begin_src lilypond
  \version "2.24.4"

  \score {
    \new Staff {
      \clef treble
      \key c \major
      \time 4/4
      \relative c' {
        c4 d4 e4 f4 |
        g1 |
      }
    }
    \layout { }
  }
#+end_src

如上，一份完整的乐谱文件由三个部分组成： =版本声明= + =音乐表达式= + =（可选）排版块= 。

- **`\new Staff`**：新建一行五线谱（谱表）。
- **`\clef treble`**：高音谱号（G 谱号）。
- **`\key c \major`**：C 大调（无升降号）。
- **`\time 4/4`**：4/4 拍（每小节 4 拍，以四分音符为一拍）。
- **`\relative c'`**：相对音高模式，以中央 C 为基准，后续音符自动取「离前一个音最近」的八度（详见 1.4 节）。
- **`\layout { }`**：空排版块，表示「输出 PDF」。
